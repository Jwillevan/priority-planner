# Top 9/Priority Planner 1.0.3 preview

- The app and Android launcher now display **Top 9/Priority Planner**.
- Daily page headings display **Top 9/Daily Planning**, with consistent capitalization.
- Related tutorial, reminder, lock-screen prompt, documentation, and test text uses the same names.
- Version metadata advances to **1.0.3+4**. The application ID, database schema, and planner behavior are unchanged from 1.0.2.

This is a development-signed preview. To update an existing installation, the APK must use the same signing certificate as the previous preview. The publishing helper verifies the signer against the published 1.0.2 APK before uploading. Export an encrypted backup before updating; install over the existing app and do not uninstall it first.

This source changelog is not proof of a completed build or release. An installable update exists only once the APK and its SHA256SUMS.txt are published under the 1.0.3 preview release on GitHub. No in-app updater is included.
