# Top 9/Priority Planner 1.0.1 preview

- Forwarding leaves the task title and Forwarded status on its original day, with an open task on the selected day. Completing the active task later preserves that original record. Repeated bulk review does not forward historical records again.
- Add or edit the delegate's first name in the task editor. The daily list displays the delegated symbol without the name.
- Choose Move to position from a task's three-dot menu, then select any rank within its ABC priority group. Intervening tasks shift automatically.
- Existing task data migrates to schema 6. Encrypted backups from schema 5 remain supported. Previously forwarded tasks retain their existing history; original-day records are created for forwards made with this version.

This is a development-signed preview, version 1.0.1+2. Install over the earlier preview to retain data; do not uninstall first. Export an encrypted backup before upgrading.
