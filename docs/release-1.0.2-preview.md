# Top 9/Priority Planner 1.0.2 preview

Task movement now uses a drag handle instead of the Move up, Move down, or Move to position menu.

Slide a task to its desired place below the A, B, or C heading. Crossing a heading changes its priority. Empty priority sections remain available, and the task list scrolls while you drag near its edge. Dropping a task keeps ABC grouping and recalculates consecutive numbering in both affected groups.

Forwarding and delegate-name behavior from 1.0.1 remain included. This version uses the existing database schema and development signing key. Install the APK over the earlier preview to keep your data; do not uninstall first. Export an encrypted backup before upgrading.
