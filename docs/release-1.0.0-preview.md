# Top 9/Priority Planner 1.0.0 preview

Offline Android planner with daily tasks and appointments, journal and attachments, weekly/monthly planning, goals, tutorials, app lock, encrypted backups, and local reminders.

Validation: Flutter analysis, 30 unit/widget tests, and Android emulator integration passed. The release APK was installed and launched on Android 16.

This is a development-signed preview. Physical-phone acceptance checks remain; see docs/phone-acceptance.md. Preserve the signing key for compatible updates.

Download the APK and SHA256SUMS.txt from the release assets. No planner data or signing keys are included in the repository.
